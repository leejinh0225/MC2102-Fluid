전체 1차 자동 전사와 독립적인 15초 구간 재전사를 대조하고, 재전사본 모든 구간의 전문용어·수식 표기를 PDF와 검토했습니다. 원래 구간과 시각은 보존했습니다. 말더듬·문장 중단 등 구어체가 남아 있으며, 발화 전체의 축어 정확성을 보증하는 문서는 아닙니다.

대괄호의 `Review note`와 수식 표기 주석은 편집자 기록이며 교수자의 발화가 아닙니다. 슬라이드와 강의에 남은 수치·설명 오류를 실제 발화처럼 바꾸지 않고 별도로 표시합니다. 특히 수문 벽반력 23,900 lbf는 주어진 모멘트식상 약 29,300 lbf로 교정해야 합니다. 실제 사고를 언급한 강의 말미의 설명은 강의자의 비유·추측이며, 사고 원인의 검증 자료로 사용하지 않습니다.
