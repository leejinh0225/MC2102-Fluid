PDF 54쪽은 영상에 직접 표시되지 않는 종합 정리이며, Part 3 마지막 구두 복습을 함께 참고합니다. [Part 3 슬라이드별 주제 구간](part03/slide-map.json)은 화면 전환의 프레임 단위 시각이 아닌 내용 대응 범위입니다.

전체 1차 자동 전사(Part 1: 138구간, Part 2: 116구간, Part 3: 148구간)를 읽고 원본 슬라이드와 전문용어·식·단위를 대조했습니다. 별도의 15초 창 재전사에서 비열비, 질량보존 부호, 압력 합력, 이동 평판의 속도 성분 등 어려운 대목을 다시 대조했습니다. Part 3도 별도 재전사를 수행하여 옆면 압력, 비정상 속도, 수두식, 지름비, 에너지식과 시간미분 수정 대목을 재검토했습니다. Part 3는 76개 구간의 용어·기호를 교정하거나 편집자 확인 사항을 덧붙였으며 삭제한 구간은 없습니다. 모든 발화를 사람이 직접 청취하여 축어 검증했다는 의미는 아닙니다.

원래 구간의 시각과 번호를 보존했습니다. 대괄호의 `Review note`는 편집자 기록이며 교수자의 발화가 아닙니다. `unclear`로 표시한 수식·수치·수식어는 임의로 완성하지 않았습니다. 특히 탱크 수위식의 부호와 비균일 압력의 합력 0 설명은 실제 발화처럼 조용히 수정하지 않고, 원래 진술과 검산 결과를 구분했습니다.

Part 3의 시간에 따른 속도 변화와 속도수두 분모 등의 자기 수정도 앞뒤 발화를 남겼습니다. 벤투리관의 지름비 필기와 인쇄식의 불일치, 질량유량의 면적 누락은 `Review note`와 HTML의 별도 대조 카드로 설명합니다. 전사에 수학적으로 옳은 식을 넣었다는 이유만으로 그것을 강의자의 발화로 간주하지 않습니다.
