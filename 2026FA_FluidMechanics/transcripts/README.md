# 영어 강의 스크립트

렉처에 해당하는 영어 강의 전체를 전사합니다. 공개 저장소에는 영상·음성이 아니라 교정된 텍스트만 보관합니다. 여러 편인 렉처는 `part01/`, `part02/` 등의 하위 폴더로 나누고, 각 편의 시작을 00:00:00으로 유지합니다.

각 렉처 폴더의 권장 파일은 다음과 같습니다.

- `lecture.txt`: 읽기 쉬운 영어 문단과 타임스탬프
- `lecture.srt`: 원본 구간을 다시 확인할 수 있는 자막
- `lecture.json`: 모델 정보와 구간별 신뢰도·시간을 보존하는 검수 데이터

`transcribe_english.py`의 원시 출력은 먼저 `private-materials/transcription-staging/`에 둡니다. 개인정보와 수업 외 발화, 잘못 인식된 전문용어를 검수한 뒤에만 이 폴더로 옮깁니다.

PDF의 표기와 전사가 충돌하면 우선 원본 음성을 다시 듣고, 수식·기호·전문용어는 PDF 문맥을 함께 사용해 교정합니다. 확정할 수 없는 부분은 임의로 메우지 않고 `[unclear 00:00:00]`처럼 표시합니다.
