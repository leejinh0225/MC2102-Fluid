# Fluid Mechanics 1 노트 집필·검증 규격

이 문서는 동역학 학습 노트의 검증된 형식을 유체역학 강의에 적용하기 위한 기준입니다. 결과물은 슬라이드 요약본이 아니라, 강의를 다시 보지 않아도 개념과 수식을 따라갈 수 있는 한국어 수업 대체 노트여야 합니다.

## 1. 입력 자료와 우선순위

한 렉처의 기본 입력은 다음 두 가지입니다.

1. 가림막을 제거하고 원문을 보존한 PDF 한 파일
2. 비공개 영어 강의 녹화 한 편에서 만든 타임스탬프 포함 스크립트

내용이 충돌할 때는 아래 순서로 판정합니다.

1. PDF에 명시된 수식·기호·정의
2. 녹화의 실제 음성과 문맥
3. 영어 자동전사 결과
4. `강의_인덱스.md`의 운영 메모
5. 일반 교과 지식으로 보강한 편집자 설명

일반 교과 지식으로 보강한 내용은 `편집자 보강`이라고 표시합니다. 주어진 자료에 없는 교수님의 의도나 시험 출제 범위를 지어내지 않습니다.

## 2. 공개·비공개 경계

- 녹화 원본, 추출 음성, 변경 금지 원본 PDF 백업, 선배 자료는 저장소 루트의 비공개 보관 영역에만 둡니다.
- 공개가 승인된 가림막 제거본과 원본 배포 사본은 `lecture_notes/`에 둡니다. 공개 사본을 만들더라도 비공개 원본 백업은 덮어쓰거나 이동하지 않습니다.
- 공개 HTML에는 녹화 URL, 파일명, 절대 경로, `<video>` 또는 `<audio>` 요소를 넣지 않습니다.
- 녹화는 렉처마다 **한 편**입니다. 동역학처럼 Overview·Contents·Problem Solving·Summary 영상으로 임의 분할하지 않습니다.
- 근거 표시는 `강의 녹화 00:12:40–00:13:25`처럼 시간 범위만 사용합니다.
- 학생 이름, 출석 확인, 수업 외 대화 등 개인정보가 전사되면 공개 스크립트에서 제거합니다.

## 3. PDF와 슬라이드 보존

- PDF의 모든 페이지를 순서대로 유지합니다.
- HTML에는 페이지마다 정확히 하나의 `.source-section`을 둡니다.
- 원본 그림, 표, 수식, 축, 단위, 기호를 잘라내거나 다시 그려 의미를 바꾸지 않습니다.
- 현재 유체역학 PDF는 4:3이므로 슬라이드 JPG는 `1440 × 1080`으로 생성하고 프레임도 4:3을 사용합니다.
- 동역학 디자인 원본의 16:9 규칙은 발표 슬라이드용 규칙입니다. 여기서는 실제 4:3 강의자료를 왜곡하지 않는 것이 우선입니다.
- 답 가림막 제거는 원본을 덮어쓰지 않고 새 파일로 출력합니다. 제거 뒤 페이지 수, 추출 텍스트, 변경 페이지를 검증합니다.

### 3.1 PDF 다운로드 규칙

- 공개 사이트의 `downloads.html`에는 각 렉처의 `가림막 제거본`과 `원본`을 한 쌍으로 제공합니다.
- 각 항목에는 렉처, 날짜 또는 `날짜 미기재`, 제목, 버전, 페이지 수, 파일 크기를 표시합니다.
- 모든 PDF 링크에는 저장소의 파일명과 같은 `download` 속성과 `type="application/pdf"`를 사용합니다.
- 가림막 제거본은 학습용 권장 자료이므로 crimson `button--primary`, 원본은 중립색 버튼으로 표시합니다.
- 강의 목록 카드와 각 렉처 HTML의 hero(상단 표지)에도 두 PDF의 직접 다운로드 버튼을 같은 순서로 둡니다. 그 뒤에 중립색 `강의 목록` 버튼을 둡니다.
- 공개 `lecture_notes` 경로의 파일은 해당 GitHub 저장소의 raw URL로 직접 연결하고 배포 폴더에 중복 복제하지 않습니다.
- `private-materials`의 변경 금지 백업이나 선배 자료는 다운로드 링크에 사용하지 않습니다.

## 4. 한 렉처의 HTML 구조

필수 순서는 다음과 같습니다.

1. Hero: 렉처 번호, 제목, 날짜 또는 `날짜 미기재`, PDF 쪽수, `비공개 녹화 1개 · 영어 스크립트 1개`
2. Overview: 이 렉처에서 무엇을 어떤 논리로 설명하는지
3. Concept summary: 슬라이드별 해설과 독립적으로 읽히는 핵심 개념 요약
4. Slide-by-slide sections: PDF 전 페이지와 강의 설명
5. Exam English: 정의 문장, 문제 지시 표현, 답안에 필요한 영어
6. Glossary: 영어 용어, 한국어 뜻, 문맥상 의미
7. Transcript audit: 잘못 들린 ASR 표현과 교정 근거
8. Sources: PDF와 비공개 녹화의 사용 범위, 편집자 보강 여부

Hero의 동작 버튼은 `가림막 제거 PDF 다운로드`, `원본 PDF 다운로드`, `강의 목록` 순서로 둡니다. 존재하지 않는 공개 영상 버튼이나 로컬 파일 열기 버튼은 만들지 않습니다.

## 5. 슬라이드별 집필 형식

각 `.source-section`은 아래 요소를 포함합니다.

- 페이지 번호와 원문 제목
- 4:3 원본 슬라이드 이미지
- 강의에서 실제로 설명한 핵심 논리
- 수식의 기호 정의, 단위, 전제, 적용 범위
- 다음 슬라이드 또는 이후 문제풀이와의 연결
- 근거 라벨: `PDF p.N`, `강의 녹화 HH:MM:SS–HH:MM:SS`, 필요 시 `편집자 보강`

단순 번역으로 끝내지 않습니다. 예를 들어 `continuum(연속체)`를 소개했다면 정의만 옮기는 것이 아니라 왜 분자 규모를 무시해도 되는지, 어떤 길이 척도에서 가정이 깨지는지, 뒤의 밀도·속도장 표현에 왜 필요한지까지 설명합니다. 단, 강의자료 밖의 설명은 반드시 보강임을 밝힙니다.

## 6. 영어와 한국어 표기

- 처음 등장하는 시험 핵심어는 `English(한국어)` 형식으로 씁니다.
- 이후에도 정의·비교·문제풀이 지점에서는 영어를 다시 노출합니다.
- 번역어만 남겨 원문 문제를 못 알아보는 상태를 만들지 않습니다.
- 기호와 첨자는 원문을 유지합니다. 밀도 `ρ`, 동점성계수 `ν`, 점성계수 `μ`처럼 서로 다른 양을 뭉개지 않습니다.
- 원문 문법이나 띄어쓰기가 어색해도 인용과 설명을 구분합니다. 조용히 의미를 바꾸지 않습니다.

## 7. 영어 스크립트 교정

자동전사본은 초안일 뿐입니다.

1. 비공개 staging 영역에서 `faster-whisper` 영어 STT 결과를 만들고 `lecture.srt`의 타임스탬프를 보존합니다.
2. `lecture.txt`를 문단화하되 각 문단에 시간 범위를 붙입니다.
3. PDF의 용어·수식과 대조합니다.
4. 애매한 구간은 음성을 다시 확인합니다.
5. 확정할 수 없으면 `[unclear HH:MM:SS]`로 남깁니다.
6. 중요한 교정은 HTML의 Transcript audit 표에 `원시 ASR / 교정 / 근거`로 기록합니다.

추측으로 그럴듯한 전문용어를 꽂아 넣는 것은 교정이 아니라 창작입니다. 유체는 잘 흐르지만 근거까지 흘려보내면 곤란합니다.

## 8. 설명 깊이와 시험 전환

각 핵심 개념에서 다음 질문에 답해야 합니다.

- 이 정의가 구분하는 대상은 무엇인가?
- 식의 각 항과 단위는 무엇인가?
- 어떤 가정에서 성립하는가?
- 흔히 혼동하는 이웃 개념은 무엇인가?
- 영어 시험에서는 어떤 문장으로 묻거나 답할 수 있는가?

`Exam English`에는 최소한 다음을 둡니다.

- 핵심 정의 문장
- 비교형 문장
- `determine`, `derive`, `assume`, `neglect`, `evaluate` 같은 문제 지시 표현
- 짧은 영문 모범답안 또는 식을 설명하는 완전한 문장

## 9. 디자인과 접근성

- crimson `#BF2B25`만 기능적 강조색으로 사용합니다.
- 본문 글꼴은 Pretendard 계열을 사용하고 제목은 sentence case를 유지합니다.
- 카드 그림자는 약하게, 정보 위계는 여백·굵기·선으로 만듭니다.
- 모든 이미지에 내용을 설명하는 `alt`를 둡니다.
- 앵커 ID는 중복되지 않아야 하며 목차 링크는 실제 섹션을 가리켜야 합니다.
- 필수 설명을 접힌 요소 안에 숨기지 않습니다.
- 별도의 `학습 목표`나 `자가 점검` 섹션을 만들지 않습니다. 개념 설명과 시험 전환에 집중합니다.

## 10. 완료 조건

다음 조건을 모두 만족해야 강의 목록의 링크를 활성화합니다.

- PDF 페이지 수와 `.source-section` 수가 동일함
- `slide-01.jpg`부터 마지막 페이지까지 빠짐없음
- 모든 슬라이드 이미지가 `1440 × 1080`임
- 독립형 핵심 개념 요약, 시험 영어, 용어집, ASR 교정표, 출처가 있음
- 미해결 `{{PLACEHOLDER}}`가 없음
- 깨진 링크, 누락 이미지, 중복 ID, 빈 `alt`가 없음
- 두 PDF 다운로드 링크의 URL·파일명·버튼 강조가 규격과 일치함
- 영상·음성 파일, 로컬 절대 경로, 비공개 보관 경로가 HTML에 없음
- 로컬 검증기와 사이트 검증기가 모두 통과함
